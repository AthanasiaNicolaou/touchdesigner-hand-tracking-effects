# My MediaPipe TouchDesigner Project

Hand-tracking visuals built in TouchDesigner using MediaPipe.

## Requirements
- TouchDesigner (free Non-Commercial version works)
- Webcam
- MediaPipe TouchDesigner plugin by Torin Blankensmith: [https://github.com/torinmb/mediapipe-touchdesigner]

## How to run
1. Download the plugin from the link above
2. Open the .toe file in TouchDesigner
3. Allow camera access when prompted
